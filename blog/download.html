O que vem no pacote completo?

O .zip traz o mesmo programa em 3 formatos — você só precisa de UM deles:

  • Instalador — instala no computador como um programa normal, com atalho na Área de Trabalho. É o recomendado para uso contínuo.
  • Portátil — abre direto, sem instalar nada. Dá pra carregar num pendrive e usar em qualquer PC.
  • Código-fonte — não é o programa, é a versão em HTML/JS usada pra montar os dois acima. Serve só para manutenção futura.
