OCULTAR / MOSTRAR O BOTÃO "TOPICS" — ORIZON
=============================================

SITUAÇÃO ATUAL (em todas as 11 páginas)
  DESKTOP (acima de 768px) : botão Topics OCULTO
  MOBILE  (até 768px)      : botão Topics VISÍVEL (e o menu abre normalmente)

Páginas: sobre, tutorial, utilidades, vagas, candidato, contato, servicos,
         cookies, ferramentas-ia, loja-sistemas, privacidade.


ONDE FICA
  Em cada página, procure por:   [TOPICS]
  Existe um único bloco de CSS, dentro de <style>, com este formato:

    /* [TOPICS-DESKTOP] botão e menu do desktop: ocultos */
    .topics-toggle, .topics-dropdown { display: none !important; }
    @media (min-width: 769px) { .topics-toggle-mobile, .topics-dropdown-mobile { display: none !important; } }
    /* [TOPICS-MOBILE] botão do mobile: visível. ... */
    /* @media (max-width: 768px) { .topics-toggle-mobile, .topics-dropdown-mobile { display: none !important; } } */
    @media (max-width: 768px) { .topics-toggle-mobile { display: inline-flex !important; } }


COMO OCULTAR NO MOBILE
  1) Descomente a linha que começa com  /* @media (max-width: 768px) ...
     (tire o /* do início e o */ do fim).
  2) Apague a linha logo abaixo dela:
        @media (max-width: 768px) { .topics-toggle-mobile { display: inline-flex !important; } }
  Resultado: botão oculto no mobile e no desktop.


COMO MOSTRAR NO MOBILE DE NOVO
  Faça o inverso: comente (/* ... */) a linha de ocultar do mobile e
  mantenha a linha  display: inline-flex !important.


COMO MOSTRAR NO DESKTOP
  Apague a linha:
        .topics-toggle, .topics-dropdown { display: none !important; }
  e a linha:
        @media (min-width: 769px) { .topics-toggle-mobile, .topics-dropdown-mobile { display: none !important; } }
  Observação: em tutorial.html e privacidade.html existe, mais abaixo no CSS,
  uma regra extra (@media (min-width: 769px) { .topics-toggle-mobile { display: none !important; } })
  que também precisaria ser removida para o botão aparecer no desktop.


QUAL FOI O ERRO CORRIGIDO
  A regra antiga era uma só, para desktop e mobile:
      .topics-toggle, .topics-toggle-mobile, .topics-dropdown, .topics-dropdown-mobile { display: none !important; }
  Problemas:
  - Nas páginas cookies, contato, vagas, privacidade e candidato ela vencia a
    regra que mostrava o botão no mobile (a que vem por último no arquivo
    ganha), então o botão sumia.
  - Em TODAS as páginas ela escondia também o menu suspenso do mobile
    (.topics-dropdown-mobile) com !important, então mesmo onde o botão
    aparecia, o menu não abria.
  Agora desktop e mobile têm regras separadas.


OBSERVAÇÃO
  O ajuste foi feito só pela leitura do CSS, sem teste no navegador.
  Confira no celular se o botão aparece e se o menu abre ao tocar.
