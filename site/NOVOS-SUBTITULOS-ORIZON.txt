Resumo
------
Os títulos antigos do corpo do texto (com ícones PNG, SVG e emoji) foram
substituídos por subtítulos no padrão "divider", o mesmo do título
"Missão da Orizon": número + eyebrow + título com degradê + linha com losango.

Arquivos alterados: sobre.html e candidato.html
Ícones removidos: apenas os que ficavam DENTRO dos títulos substituídos.


ESTRUTURA DE CADA SUBTÍTULO
---------------------------
<div class="orizon-divider-section ods-sub">
  <span class="ods-num">01.1</span>            <- número
  <span class="ods-eyebrow">Quem somos</span>  <- texto pequeno acima do título
  <h2 class="ods-title">Título aqui</h2>       <- título (degradê + brilho no escuro)
  <span class="ods-line"><i></i><b></b><i></i></span>   <- linha com losango
</div>

Observações:
- Quando o título tinha duas cores (ost-w1 / ost-w2), os spans foram mantidos
  dentro do h2.ods-title. Isso preserva a compatibilidade com o dicionário de
  tradução automática, que traduz cada pedaço de texto separadamente.
- Os ids que o JS usa (conexao, numeros, atuacao, visao-futuro) ficam no
  próprio <h2>, não na div. A tradução por id troca o texto desse elemento;
  se o id estivesse na div, ela apagaria número, eyebrow e linha.

COMO ADICIONAR UM NOVO SUBTÍTULO
--------------------------------
1. Copie a estrutura da seção "ESTRUTURA DE CADA SUBTÍTULO".
2. Escolha o próximo número (ex.: 01.5) e um eyebrow curto (2 a 4 palavras).
3. Se o menu de tópicos ou a tradução por id precisar encontrar o título,
   use id no <h2> (sobre.html) ou na div (candidato.html), como acima.
4. Cadastre o eyebrow em literalTranslations (en/es), na mesma lista onde
   estão "Por que existimos" e "Para onde vamos" (sobre.html) ou no início
   do bloco (candidato.html).

CORES DOS TÍTULOS — BICOLOR (rodada atual)
------------------------------------------
Pedido: título em duas cores.
  Modo escuro : parte em AZUL NEON (#00c8ff, com brilho) + parte em BRANCO (#fff)
  Modo claro  : parte em AZUL normal (#1d4ed8) + parte em PRETO (#000)

Como funciona:
- O degradê do .ods-title foi desligado (background:none) e a cor passou a vir
  dos spans: .ost-w1 = cor 1 (azul / azul neon) e .ost-w2 = cor 2 (preto / branco).
- Vale para TODOS os títulos .ods-title: subtítulos 01.x/02.x/03.x do sobre.html,
  os de 01 a 06 do candidato.html e também "Missão da Orizon" e "Visão da Orizon".
- Títulos que vieram só com texto (Missão da Orizon, Visão da Orizon, Materiais
  para Download) ou que a tradução recriou sem spans (visao-futuro) são divididos
  por um pequeno script (<script id="orizon-ods-split">, no fim do <body>):
  1ª palavra = cor 1, restante = cor 2. Ele observa o título, então continua
  funcionando depois de trocar o idioma (PT/EN/ES).
- Títulos de uma palavra só (Comportamento) ficam inteiros na cor 1.
- Regras com !important, porque o sobre.html tem "body.dark-mode h2 {color:#00c8ff
  !important}" que, sem isso, pintaria tudo de azul.

Onde ajustar:
- Cores: bloco "Cores bicolores dos títulos" no fim do CSS do divider
  (sobre.html: bloco orizon-pagina-unica | candidato.html: <style id="orizon-divider-titles">).
- Para inverter (cor 2 na 1ª parte), troque as cores de .ost-w1 e .ost-w2.

BOTÃO DO GLOBO (TRADUTOR EM VOZ) — REMOVIDO DO DESKTOP
------------------------------------------------------
O botão redondo com o ícone 🌐 que ficava no canto superior direito do header
(ao lado do botão de tema) foi tirado do desktop em sobre.html e candidato.html.
No mobile (até 640px) ele já estava escondido desde antes.

O que foi feito:
- O HTML do botão foi MANTIDO no arquivo (só ficou invisível), porque o JavaScript
  do tradutor (efeito "listening" do microfone e o fechar-ao-clicar-fora) procura
  esse elemento pelo id voiceTranslatorToggle. Apagar o HTML causaria erro.
- Foi adicionada a regra abaixo no <style id="mobile-header-compact">
  (logo antes do @media (max-width: 640px)):
      .voice-translator-toggle { display: none !important; }
- O painel do Tradutor em Voz continua funcionando: abre pelo link "Tradutor"
  do rodapé (menu Navegação).

HTML original do botão (dentro de <div class="top-right-buttons" id="topRightButtons">,
logo depois do botão de tema):
    <button class="voice-translator-toggle" id="voiceTranslatorToggle" onclick="toggleVoiceTranslator()" title="Tradutor em Voz">
    <span id="vtIcon">🌐</span>
    </button>

Aparência original:
- Modo escuro : fundo preto, borda azul neon (#00c8ff), globo azul neon, com brilho.
- Modo claro  : fundo preto 45% transparente, borda branca, globo branco.
- Formato de pílula (border-radius 50px, 50px de altura, 50px de largura mínima).

COMO RESTAURAR O BOTÃO NO DESKTOP

BOTÃO "TOPICS" — OCULTO NO DESKTOP E NO MOBILE
----------------------------------------------
O botão "Topics" (pílula branca com borda, no header, ao lado de Voltar e Menu)
foi ocultado em sobre.html e candidato.html, tanto no desktop quanto no celular.

O que foi feito:
- O HTML dos botões foi MANTIDO (só ficou invisível), porque o JavaScript
  (toggleTopics / toggleTopicsMobile e os menus suspensos) procura esses elementos
  pelo id. Apagar o HTML poderia causar erro.
- Foi adicionada a regra abaixo no <style id="mobile-header-compact">:
      .topics-toggle, .topics-toggle-mobile, .topics-dropdown, .topics-dropdown-mobile { display: none !important; }
  (.topics-toggle = botão do desktop | .topics-toggle-mobile = botão do mobile |
   .topics-dropdown / .topics-dropdown-mobile = listas de tópicos que abriam ao clicar)

HTML original dos botões (dentro de <div class="top-left-buttons" id="topLeftButtons">):
    <button class="topics-toggle" id="topicsToggle" onclick="toggleTopics()" title="Topics">Topics</button>
    <button class="topics-toggle-mobile" id="topicsToggleMobile" onclick="toggleTopicsMobile()" title="Topics">Topics</button>
  (no sobre.html o botão mobile tem também style="width:fit-content;min-width:0;max-width:none;")

Aparência original:
- Modo escuro : fundo preto, borda azul neon (#00c8ff), texto azul neon, com brilho.
- Modo claro  : pílula transparente com borda branca e texto branco (sobre o header azul).

COMO RESTAURAR O TOPICS
1. Em cada arquivo, procure o comentário "TOPICS: botão "Topics" (desktop e mobile)".
2. Apague a linha ".topics-toggle, .topics-toggle-mobile, .topics-dropdown, ..."
   que fica logo abaixo dele.
3. Os menus de tópicos voltam a funcionar como antes (o JS não foi alterado).

HEADER MENOS ALTO NO DESKTOP
----------------------------
Pedido: no desktop o header (faixa azul com ORIZON) podia ficar menos alto.

Valores ORIGINAIS (desktop):
- .header          -> min-height: 220px
- .header-content  -> padding: 2.5rem 1rem 2rem

Valores NOVOS (só telas com 769px ou mais; mobile/tablet não mudam):
- .header          -> min-height: 168px
- .header-content  -> padding: 1.1rem 1rem 1rem
Regra no <style id="mobile-header-compact">, dentro de @media (min-width: 769px).
O logo, os textos e os botões Voltar / Menu / tema não mudaram de tamanho,
só o espaço vazio em cima e embaixo diminuiu.

Para ajustar: altere o min-height (menor = header mais baixo) e o padding do
.header-content (o primeiro valor é o espaço acima do logo, o terceiro o abaixo).
Para voltar ao antigo: apague o bloco @media (min-width: 769px) desse comentário
"DESKTOP (769px ou mais): header menos alto" em cada arquivo.

ESPAÇAMENTO PADRÃO DOS TÍTULOS — IGUAL NAS 11 PÁGINAS
Objetivo: não ter espaços vazios exagerados em volta dos títulos. Bloco único,
colado no fim do <head> de cada página: <style id="orizon-espacamento-padrao">.
Regras (usam !important porque cada página tinha uma margem própria):
  Desktop
  - Subtítulo (.ods-sub):  margem de cima 2rem | de baixo 1.2rem  (antes 3rem / 1.4rem)
  - Título principal (sem .ods-sub, ex.: Missão/Visão da Orizon): 3rem em cima (antes 4.5rem no sobre)
  - Título que é o PRIMEIRO item de uma section/container (que já tem padding):
    margem de cima 0, pra não somar com o padding da section
  - Linha com losango (.ods-line): 0.8rem de distância do título (antes 1rem)
  Mobile (até 768px)
  - Subtítulo: 1.4rem em cima | 1rem embaixo; principal: 2rem em cima; primeiro item: 0
Não são afetados: .ods-inline (já compacto) e .ods-slate (claquete do tutorial.html,
que tem regra própria).
Para ajustar tudo de uma vez: mude os números desse bloco (o mesmo em todas as páginas).
Para voltar ao antigo: apague o <style id="orizon-espacamento-padrao"> de cada página.
Pendente de conferência visual: os valores foram escolhidos pelo CSS, sem renderizar a
página; se algum título ainda ficar com muito/pouco espaço, diga qual página e seção.
