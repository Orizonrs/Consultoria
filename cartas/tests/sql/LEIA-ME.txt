TESTE SQL REAL (R13)
====================
O que é: roda sql/cr-schema.sql INTEIRO e depois 40 verificações + 2 de permissão das regras do M15
(aditivo / renovação / rescisão) num PostgreSQL de verdade. NÃO é o Supabase de produção.

Como rodar (num PostgreSQL local, banco vazio de teste — NUNCA no banco de produção):
  createdb orizon_teste
  sh tests/sql/rodar-m15.sh orizon_teste
Resultado esperado (2 linhas):
  NOTICE:  M15 SQL: 40 verificações OK
  NOTICE:  M15 SQL: permissões OK (anon bloqueado, sem login bloqueado)
Se alguma regra falhar, aparece "FALHOU [Txx ...]" e o script para.

Arquivos:
  stub-supabase.sql  papéis anon/authenticated, auth.uid()/auth.jwt() e as 2 tabelas-base (cr_contratos, cr_signatarios)
  m15-teste.sql      os casos (inclui assinar de verdade pelo cr_assinar até o contrato virar "assinado")
  rodar-m15.sh       stub + schema + teste

Limite honesto: o stub imita o Supabase, não é ele. Políticas RLS, cabeçalhos HTTP (IP/dispositivo) e o PostgREST
só são conferidos de verdade no teste manual com o Supabase real (M-41 a M-48).
