1. BOTOES (BLOCO botoes-entrelacados)
-------------------------------------
- Cada botao ganha a classe "hk-bt" via JS e um SVG proprio (classe "hk") desenhado atras do texto. Quem recebe o clique e o desenho (path), nao a caixa retangular.
- Grupos: [Menu] sozinho; [Tema, Acesso] juntos (.acesso-wrap, ordem fixa do DOM: Tema order 0, Acesso order 1, em todos os tamanhos; o CSS antigo invertia no celular).
- Menu sozinho = pilula: no JS, quando o grupo tem 1 botao (n===1) todos os raios = (altura - 2)/2.
- Tema e Acesso: Tema tem gancho na direita (hasR), Acesso na esquerda (hasL). Margem negativa -(o-g) no segundo botao; folga entre pecas --hk-g.
- Variaveis (:root): --hk-o gancho (26px / 20px celular / 18px ate 340) | --hk-g folga (4px / 3px celular) | --hk-pad padding (22px / 16px ate 768 / 14px ate 480 / 11px ate 340) | --hk-ext (10px / 8px / 6px).
- Posicao no celular (ate 480px): Menu top .75rem left .75rem; Acesso/Tema top .75rem right .75rem.
- hover e :active nao movem o botao (transform:none), para o gancho nao desencaixar.
- Fonte: DM Sans 700 (fallback Segoe UI/system-ui).
- Para desativar: apague o <style id="botoes-entrelacados"> e o <script id="botoes-entrelacados-js"> e volte o HTML do Menu para o original (3 linhas soltas, sem .mt-ico/.mt-lbl).
